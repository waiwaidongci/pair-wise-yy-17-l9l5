# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 异常处置流程（处置台）

1. **登记派发**：异常记录在「处置台」登记，必须指定处置人（限巡测处置名单）和复查期限；关联样点自动升为重点保护。
2. **改派**：改派必须填写原因，原处置人 → 新处置人、原因、操作人、时间写入 `handover` 与历史记录。
3. **复查提交**：仅当前处置人或值班负责人（右上角切换当前值班人员）可提交，须填入温度、湿度、CO2 三项。
4. **判定**：三项均在样点基准允许范围内（基准 ± 配置偏差，见 `project.config.js → handling.metrics`）才置为「已复查」；任一项超范围或缺失即退回为「复查退回」，本次数据全部保留并显示超限明细。
5. **基准调整重判**：在「样点档案」调整基准后，所有未完成复查的记录自动按新范围重新判定（已复查记录不变）；重判全部合格只回到「异常待复查」，仍需处置人或值班负责人重新提交才闭环。

列表按 复查退回 → 异常待复查 → 已复查排序，卡片展示当前处置人、复查期限（逾期标红）、三项指标合格/超限/缺项状态及最近一次改派交接。

## 分层

- 规则：`project.config.js`（名单、指标偏差、视图）与 `rules/handling.js`（登记/改派/复查/重判纯业务逻辑）
- 存储与接口：`server.js`（`/api/desk/*`、`/api/sites/:id/baseline`，数据写 `data/db.json`）
- 页面：`public/app.js`（通用列表/表单）+ `public/desk.js`（处置台与基准调整交互）

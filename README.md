# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 异常处置闭环

巡测记录里的异常不再被一键标为“已复查”，统一走「处置台」：

1. **登记 → 派单**：在巡测记录点「标记异常」，进入`待派单`；在处置台「派单」时指定**处置人**和**复查期限**。
2. **改派**：必须填写**原因**，原处置人→新处置人全程写入历史。
3. **提交复查**：只能由**当前处置人或值班负责人**提交，需填入**温度、湿度、CO2**。三项都落在样点基准允许范围（基准 ± 容差）内才`已复查`；任一项超出即`复查退回`，读数与基准快照保留留痕，整改后可重新提交。
4. **基准调整**：调整样点基准须写明原因；未完成复查在列表与提交时**始终按当前基准重新判定**。

列表能看到当前处置人、复查期限（逾期高亮）、还缺哪项，以及三项读数相对基准的即时比对。

## 分层

- `lib/rules.js`：领域规则（纯函数，无 IO）——范围判定、派单/改派/复查流转、控制台摘要。
- `lib/store.js`：`db.json` 读写与遗留数据迁移。
- `project.config.js`：容差、值班负责人、状态色、处置台表单等**配置数据**。
- `server.js`：HTTP 层，处置台接口为 `/api/console/...`，巡测流程字段禁止经普通 PATCH 改写。
- `public/`：页面（看板 / 处置台 / 样点 / 巡测）。

规则测试：
